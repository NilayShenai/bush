Bush Docs

Bush Docs

Bush is a fast, lightweight Unix shell written in Go with integrated developer tooling, zero external runtime dependencies, and truecolor pastel aesthetics.

Get Started

Install Bush and run. Zero configuration required to get up and running.

Build from Source (requires Go 1.19+):

git clone https://github.com/NilayShenai/bush.git
cd bush
go build -ldflags="-s -w" -o bush main.go
./bush

Set as Default Login Shell:

sudo cp bush /usr/local/bin/bush
echo "/usr/local/bin/bush" | sudo tee -a /etc/shells
chsh -s /usr/local/bin/bush

Featured Documentation

Frecency Jump (z)
Built-in frequency-recency directory teleportation. Teleport anywhere with z <query> without external tools like zoxide.
Command Blast Radius Guard
Heuristic safety guard intercepting destructive commands (rm -rf *, git reset --hard, git push -f, dd).
Port Doctor & Killer
Inspect listening processes and release held ports (port 3000 / killport 3000) to resolve EADDRINUSE in one command.
Differential Live Watcher
Periodic command runner (watch 1s "cat /proc/loadavg") with real-time diff highlighting of changed lines.
Safe Environment Loader
Load .env files directly with envload, featuring automatic masking of tokens, passwords, and secret keys.
Pipeline Output Memoizer
Cache expensive command outputs in memory with memo <cmd> and replay instantly without re-fetching network queries.

Configuration

Bush is configured through TOML in ~/.config/bush/config.toml:

[shell]
greeting_banner = true
motto = "A shell for people of refined taste."
history_limit = 5000

[guard]
enabled = true
file_threshold = 10

[prompt]
multiline = true
symbol = "❯ "
badges = ["badge", "user", "dir", "git", "duration", "status"]

[theme]
name = "lavender" # "lavender", "nord", "tokyo_night", "rose_pine", "custom"

[autosuggest]
enabled = true
suggest_history = true
suggest_subcommands = true
suggest_files = true
suggest_binaries = true

POSIX Engine & Job Control

Handwritten recursive-descent parser and AST pipeline execution layer:

Feature Syntax Description
Pipelines cmd1 | cmd2 | cmd3 Concurrent process pipes
Redirection >, >>, <, 2>, 2>&1 Stream routing to files and descriptors
Chaining ;, &&, || Sequential and short-circuit operators
Job Control &, jobs, fg, bg POSIX process group backgrounding
Expansions $VAR, ~, $(cmd) Variables, tildes, and subshell substitution

Keybindings

Keybinding Action
Tab Accept prediction or trigger context-aware completion
Right Arrow Accept inline ghost autosuggestion
Up / Down History search with prefix filtering
Ctrl + R / Ctrl + P Interactive fuzzy command palette
Ctrl + A / Ctrl + E Beginning / end of line
Ctrl + U / Ctrl + K Kill text to start / end of line
Ctrl + C Cancel current command line
Ctrl + D Exit shell (on empty line)
