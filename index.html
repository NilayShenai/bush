Bush Docs

Bush is an open-source Unix shell written in Go. It delivers full POSIX pipeline execution with integrated developer tools and zero external runtime dependencies.

Get Started

Install Bush and run. Zero configuration required to get up and running.

Install Script

Run the universal installer to download the precompiled binary for Linux and macOS:

GitHub Repository ↗ 
curl -fsSL https://raw.githubusercontent.com/NilayShenai/bush/main/install.sh | bash

Build from Source

Prerequisites: Go 1.19 or higher.

git clone https://github.com/NilayShenai/bush.git
cd bush
make install

Set as Default Login Shell:

echo "/usr/local/bin/bush" | sudo tee -a /etc/shells
chsh -s /usr/local/bin/bush

Featured Documentation

Frecency Jump (z)
Built-in frequency-recency directory teleportation. Jump anywhere with z <query> without external tools like zoxide.
Command Blast Radius Guard
Heuristic safety guard intercepting destructive commands (rm -rf *, git reset --hard, git push -f, dd).
Port Doctor & Killer
Inspect listening processes and release held ports (port 22, killport 3000) to resolve EADDRINUSE in one command.
Differential Live Watcher
Periodic command runner (watch 1s "cat /proc/loadavg") with real-time diff highlighting of changed lines.
Safe Environment Loader
Load .env files directly with envload, featuring automatic masking of tokens, passwords, and secret keys.
Pipeline Output Memoizer
Cache expensive command outputs in memory with memo <cmd> and replay instantly without re-fetching network queries.
Auto-Updater (update)
Keep Bush up to date directly from GitHub releases with update. Check for new releases without installing via update check.

Configuration

Bush is configured through TOML in ~/.config/bush/config.toml:

[shell]
greeting_banner = true
motto = "A shell for people of refined taste."
history_limit = 5000

[guard]
enabled = true
file_threshold = 10

[prompt]
multiline = true
symbol = "❯ "
badges = ["badge", "user", "dir", "git", "duration", "status"]

[theme]
name = "lavender" # "lavender", "nord", "tokyo_night", "rose_pine", "custom"

[autosuggest]
enabled = true
suggest_history = true
suggest_subcommands = true
suggest_files = true
suggest_binaries = true

POSIX Engine & Job Control

Handwritten recursive-descent parser and AST pipeline execution layer:

Feature Syntax Description
Pipelines cmd1 | cmd2 | cmd3 Concurrent process pipes with OS descriptors
Redirection >, >>, <, 2>, 2>&1 Stream routing to files and file descriptors
Chaining ;, &&, || Sequential and short-circuit boolean operators
Job Control &, jobs, fg, bg POSIX process group backgrounding
Expansions $VAR, ~, $(cmd) Variables, tilde expansion, and subshell substitution
