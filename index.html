bush

"A shell for people of refined taste."

Bush is a high-performance, single-binary Unix shell engineered in Go. Developed with zero external dependencies, it fuses POSIX compliance with an integrated developer engine: native frequency-recency directory teleportation, command blast-radius safety heuristics, live differential output diffing, and port diagnostics.

git clone https://github.com/NilayShenai/bush.git && cd bush && go build

DEVELOPER SUITE & INNOVATIONS

Eliminating the traditional clutter of external Python scripts, Rust binaries, and plugin managers, Bush packages critical engineering utilities directly into the shell binary:

FRECENCY TELEPORTATION z <query>
Evaluates visited directories with an internal frequency-recency decay algorithm. Instantly jump across filesystems using partial substrings without third-party plugins.
BLAST RADIUS GUARD [guard]
Heuristic barrier intercepting high-blast commands (rm -rf *, git reset --hard, git push -f, dd). Scans target filesystem depth and prompts for verification.
PORT DOCTOR & TERMINATOR port / killport
Scan listening TCP/UDP ports, inspecting executable names, PID, and bound interfaces. Terminate offending processes to clear EADDRINUSE in a single command.
DIFFERENTIAL WATCHER watch <int> <cmd>
Continuous execution loop comparing output against previous runs line-by-line, highlighting mutated lines in high-visibility cyan and lime.
PIPELINE OUTPUT MEMOIZER memo <cmd>
Buffers stdout in-memory. Replay output into subsequent pipes (memo | jq .) immediately without re-triggering expensive network requests.
SAFE ENVIRONMENT LOADER envload
Parse and export .env files directly into the active session with automatic masking of sensitive credentials (tokens, passwords, keys).
COMPACT GIT HUD g
Dense 3-line repository overview displaying branch tracking, staged/modified/untracked counters, and latest commit details.
COMMAND DOCTOR why
Examines non-zero exit statuses, differentiating between missing binaries, missing script interpreters, and typo distances.

POSIX SPECIFICATION & RUNTIME

Bush implements standard Unix shell grammar through a handwritten recursive-descent parser and an AST pipeline executor:

SUBSYSTEM GRAMMAR / SYNTAX BEHAVIOR
Pipelines cmd1 | cmd2 | cmd3 Concurrent process execution with connected OS pipe descriptors
Redirections >, >>, <, 2>, 2>&1, &> Accurate stream redirection to filesystem paths and descriptors
Chaining ;, &&, || Sequential, short-circuit conditional AND, and short-circuit OR
Job Control &, jobs, fg, bg POSIX process group management with foreground TTY handover
Expansions $VAR, ${VAR}, $?, $$, ~, $(cmd) Tilde expansion, variable lookup, subshell command substitution
Privilege Sync EUID == 0 Dynamic red-alert prompt bar and [ root ] capsule activation

CONFIGURATION (config.toml)

Declarative settings are resolved from ~/.config/bush/config.toml (with automatic fallback to ~/.bush.toml). Reload settings live using config reload:

~/.config/bush/config.toml 
[shell]
greeting_banner = true
motto = "A shell for people of refined taste."
history_limit = 5000

[guard]
enabled = true
file_threshold = 10

[prompt]
multiline = true
symbol = "❯ "
badges = ["badge", "user", "dir", "git", "duration", "status"]
max_dir_depth = 4
duration_threshold_ms = 5
show_git = true
show_git_dirty = true

[theme]
name = "lavender" # "lavender", "nord", "tokyo_night", "rose_pine", "custom"

[autosuggest]
enabled = true
suggest_history = true
suggest_subcommands = true
suggest_files = true
suggest_binaries = true

[aliases]
ll = "ls -la --color=auto"
gs = "git status"
gp = "git pull"
